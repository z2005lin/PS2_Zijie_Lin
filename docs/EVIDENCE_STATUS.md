# Evidence status

This file separates completed artifacts from claims that remain hypotheses or future work.

## Completed and included

- one-shot H/L anti-coordination game specification;
- private Urgent/Patient types and baseline payoff calibration;
- complete-information equilibrium benchmark;
- type-dependent Bayesian best-response logic;
- three-treatment computational design;
- clean and fresh-run executed notebooks;
- simulated congestion, differentiation, type-sorting, and welfare outputs;
- current Hugging Face behavioral game;
- teaser figure;
- proposal PDF and editable Overleaf source; and
- reproducibility commands and dependency list.

## Simulated, not empirical

All notebook tables and plots are generated by the stated behavioral rules and random seeds. They are conditional model outputs. They are not:

- observed Algorand transactions;
- measured network capacity or confirmation outcomes;
- bids, payments, utilities, or revenues from participants;
- causal treatment effects;
- verified wallet-interface effects; or
- evidence that Algorand should deploy the signal.

## Still required before an empirical claim

- protocol-grounded mapping from H/L actions to fees;
- congestion and confirmation rules;
- payoff and type-prior calibration;
- sample-size and power analysis;
- ethics and consent decisions;
- preregistered hypotheses and exclusion rules;
- participant recruitment and laboratory execution;
- locked data, analysis log, and fresh verification run; and
- external peer or instructor review.

## Artifact parity

The GitHub repository, Colab notebook, Hugging Face interface, proposal, and future poster should use the same game, payoff definitions, treatment names, and evidence labels. If one artifact changes, the others should be reviewed before making a release.
